## Featured project

**Macao visitor source markets, 2024–2025** examines how the visitor mix changed and which markets contributed most to the total increase. Using official annual records, the analysis distinguishes growth rate from growth contribution: Taiwan had the highest proportional growth (19.4%), while mainland visitors accounted for 88.0% of additional arrivals.

The findings describe visits across two years; they do not establish causes or visitor spending. The project repository contains attributed source data, Python analysis, two visualizations, calculation checks, and reproduction instructions.

**Project status:** Ongoing — analysis and peer review complete; explanation revised; extension planned.
